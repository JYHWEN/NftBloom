# NftBloom

NftBloom is a cloud-based, distributed infrastructure for real-time NFT data processing, enabling scalable Marketplace Engine operations.

With NftBloom, you get a lightweight tool that stays out of your way.

**What you get**

- NftBloom is a cloud-based, distributed
- infrastructure for real-time NFT data
- processing, enabling scalable Marketplace Engine

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftBloom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftBloom, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
